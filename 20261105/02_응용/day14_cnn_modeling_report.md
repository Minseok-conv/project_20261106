# Day 14 이미지 분류 모델링 보고서

## 1. 작업 개요

본 프로젝트는 **사전학습된 교육용 CNN의 Backbone을 활용하여 3개 클래스의
이미지를 분류하는 전이학습(Transfer Learning) 실험**이다. 정상 이미지가
포함된 `train` 데이터로 모델을 학습하고 `valid` 데이터로 성능을
평가한다. **Test 데이터는 사용하지 않는다.**

본 실험의 주요 목적은 다음과 같다.

-   사전학습 Backbone을 고정하고 분류 Head만 학습하는 기준선 수립
-   Backbone 일부 계층까지 학습하는 Partial Fine-tuning 효과 비교
-   클래스 불균형 보정을 위한 가중 Cross-Entropy Loss의 효과 비교
-   정확도, Macro F1, 특정 클래스 Recall 및 Grad-CAM을 활용한 결과 분석

## 2. 데이터 구성 및 전처리

`torchvision.datasets.ImageFolder`를 통해 `data/train`과 `data/valid`
폴더의 이미지를 읽는다. 폴더 이름을 클래스 레이블로 사용하며, 이미지와
레이블을 각각 `X_train`, `y_train`, `X_valid`, `y_valid`에 저장한다.

전처리는 다음 두 단계로 이루어진다.

1.  `Resize((32, 32))`: 모든 이미지를 32×32 픽셀로 조정
2.  `ToTensor()`: 일반적인 8비트 RGB 이미지의 픽셀값을 `[0, 1]` 범위로
    변환하고 `(C, H, W)` 형태의 텐서로 구성

이후 `torch.stack()`을 사용해 모든 이미지를 `(N, 3, 32, 32)` 형태의 배치
텐서로 결합한다. 사전학습 가중치의 입력 조건을 유지하기 위해 ImageNet용
평균·표준편차 정규화는 적용하지 않는다.

## 3. 모델 구조 및 전이학습

모델은 `nn.Sequential` 기반의 소형 CNN으로, 두 개의 합성곱 계층과 Batch
Normalization, ReLU, Pooling, Flatten, Linear Head로 구성된다.

  -----------------------------------------------------------------------
  구분                    주요 구성               역할
  ----------------------- ----------------------- -----------------------
  Backbone (0\~8번)       Conv2d, BatchNorm2d,    이미지 특징 추출
                          ReLU, Pooling, Flatten  

  Head (9번)              `Linear(256, 3)`        3개 클래스의 Logit 산출
  -----------------------------------------------------------------------

Backbone의 가중치는 `source_backbone.npz`에서 불러온다. 이는 **ImageNet
ResNet18 가중치가 아니라 별도 합성 데이터로 사전학습한 교육용
가중치**다.

전체 파라미터를 동결한 뒤 실험 전략에 따라 학습할 계층만
`requires_grad=True`로 설정한다. `model.eval()`을 유지해 BatchNorm의
running 통계를 고정하며, 이는 기울기 계산을 금지하는 것과는 별개의
설정이다.

## 4. 실험 설계

세 가지 실험 조건을 비교한다.

  ------------------------------------------------------------------------
  실험             학습 대상        손실 함수             학습 파라미터 수
  ---------------- ---------------- ---------------- ---------------------
  Head 기준선      Head(9번)        일반                               771
  (`head`, `none`)                  Cross-Entropy    

  Partial          Conv2d(4번) +    일반                             1,923
  (`partial`,      Head(9번)        Cross-Entropy    
  `none`)                                            

  Head + Weight    Head(9번)        클래스 가중                        771
  (`head`,                          Cross-Entropy    
  `weight`)                                          
  ------------------------------------------------------------------------

클래스 가중치는 각 클래스의 학습 샘플 수의 역수에 비례하도록 계산하고,
평균이 1이 되도록 정규화한다. 소수 클래스의 오류가 손실 함수에 더 큰
영향을 주도록 하기 위한 방법이다.

모든 실험에서 다음 조건을 공통으로 사용한다.

-   랜덤 시드: `14`
-   Optimizer: AdamW
-   Learning rate: `0.003`
-   Weight decay: `0.0001`
-   Epoch: `8`
-   학습 방식: 전체 `X_train`을 한 번에 입력하는 Full-batch 학습
-   모델 선택: 매 Epoch의 **가중치 없는 Validation Cross-Entropy
    Loss**가 가장 낮은 시점의 상태 복원

세 실험 모두 동일한 데이터와 초기화 조건을 사용하지만, 실제 결과는
제공되지 않았으므로 우열은 확정할 수 없다.

## 5. 평가 및 결과물

검증 데이터에 대해 다음 지표를 계산한다.

-   **Accuracy**: 전체 샘플 중 정확히 예측한 비율
-   **Macro F1**: 각 클래스 F1 Score의 산술평균으로, 클래스별 성능을
    동등하게 반영
-   **Triangle Recall**: 클래스 인덱스 `2`에 해당하는 실제 샘플 중
    올바르게 검출한 비율
-   **Best Epoch**: Validation Loss가 가장 낮은 학습 시점
-   **Trainable Parameters**: 실제 업데이트 가능한 파라미터 개수
-   **Elapsed Time**: 학습 및 검증 루프의 소요 시간

주요 산출물은 다음과 같다.

  -----------------------------------------------------------------------
  파일                                내용
  ----------------------------------- -----------------------------------
  `metrics.csv`                       세 실험의 최종 검증 성능 비교

  `history.csv`                       실험별 Epoch에 따른 Validation Loss

  `predictions.csv`                   마지막 Head + Weight 모델의 파일명,
                                      정답, 예측, 최대 Softmax 확률

  `confusion.csv`                     마지막 Head + Weight 모델의
                                      혼동행렬

  `project_error_*.png`               마지막 모델의 오분류 이미지 최대
                                      8장

  `project_cam.png`                   마지막 모델의 선택 이미지에 대한
                                      Grad-CAM 시각화
  -----------------------------------------------------------------------

**주의:** `predictions.csv`, `confusion.csv`, 오분류 이미지 및
Grad-CAM은 반복문의 마지막 실험인 **Head + Weight** 모델을 기준으로
생성된다. 세 모델 중 성능이 가장 좋은 모델을 자동으로 선택한 결과는
아니다.

Grad-CAM은 선택한 예측 클래스의 Logit을 특징 맵에 대해 미분하여 공간적
반응을 시각화한다. 해당 시각화는 모델의 반응을 설명하는 보조 자료이며,
올바른 인식 근거나 인과관계를 증명하지 않는다.

## 6. 결론

본 프로젝트는 **사전학습 특징 추출기를 재사용하는 전이학습과 클래스
불균형 보정의 효과를 비교할 수 있는 기초 실험 체계**를 구현했다.

Head-only는 가장 적은 파라미터를 학습하는 기준선이고, Partial
Fine-tuning은 추가적인 특징 조정의 효과를 검토하는 조건이다. Head +
Weight는 모델 구조와 학습 파라미터 수를 유지하면서 소수 클래스에 대한
손실 비중을 변경한다.

다만 제공된 것은 **실험 코드이며 실제 평가 수치가 아니므로**, Partial
Fine-tuning이나 클래스 가중치 적용이 성능을 개선했다고 결론 내릴 수
없다. 실제 `metrics.csv`에서 Accuracy, Macro F1, Triangle Recall을 함께
비교해야 한다. 특히 소수 클래스 Recall의 개선이 다른 클래스의
Precision이나 전체 정확도 하락을 동반하는지 확인할 필요가 있다.

## 7. 모델링의 한계

### 7.1 Test 데이터에 대한 최종 일반화 성능 미확인

코드에서는 Validation 데이터로 최적 Epoch를 선택하고 동일한 데이터로
성능을 보고한다. 따라서 보고된 지표는 **검증 성능**이지 독립 Test
데이터에 대한 최종 일반화 성능이 아니다. Test 데이터는 학습 및 모델
선택이 끝난 후 별도로 평가해야 한다.

### 7.2 제한적인 모델 및 사전학습 환경

작은 교육용 CNN과 합성 데이터 기반 Backbone을 사용한다. 실제 산업용
이미지의 복잡한 배경, 조명, 해상도, 분포 변화에 대한 성능을 이
결과만으로 추정하기 어렵다.

### 7.3 짧은 학습과 제한된 하이퍼파라미터 탐색

8 Epoch, 단일 학습률, 단일 랜덤 시드만 사용한다. 최적의 학습률이나 Epoch
수를 탐색하지 않았으며, 여러 시드에서 반복한 결과의 평균과 변동성도
확인하지 않는다.

### 7.4 Full-batch 학습의 제약

모든 학습 이미지를 한 번에 메모리에 올려 Epoch당 한 번 업데이트한다.
데이터 규모가 커지면 메모리 부담이 증가하며, 일반적인 미니배치 학습과는
최적화 특성이 달라질 수 있다.

### 7.5 클래스 가중치의 부작용 가능성

클래스 빈도의 역수로 손실을 보정하면 소수 클래스 Recall이 개선될
가능성이 있지만, 다수 클래스의 성능이나 예측 확률의 보정 정도가 악화될
수 있다. 클래스별 Precision·Recall·F1 및 혼동행렬을 함께 분석해야 한다.

### 7.6 제한된 Fine-tuning 범위

Partial 전략은 두 번째 합성곱 계층만 추가로 학습하며 BatchNorm의 running
통계는 고정한다. 따라서 Backbone 전체를 미세 조정하는 경우와 결과가 다를
수 있다.

### 7.7 설명 가능성 및 확률 해석의 한계

Grad-CAM은 특정 출력 점수에 대한 근사적 시각화일 뿐, 모델의 실제 판단
원인을 입증하지 않는다. `confidence` 열의 최대 Softmax 값 역시 예측의
정확성을 보장하는 보정된 신뢰도가 아니다.

## 8. 향후 개선 방향

1.  **독립 Test 평가:** 모델 선택이 완료된 후 별도 Test 데이터로 최종
    성능 측정
2.  **반복 실험:** 여러 랜덤 시드에서 평균과 표준편차 보고
3.  **하이퍼파라미터 탐색:** 학습률, Epoch, Weight Decay 및 동결 해제
    범위 비교
4.  **클래스별 분석:** 클래스별 Precision·Recall·F1, 혼동행렬 및 오류
    사례 검토
5.  **샘플링 방식 비교:** WeightedRandomSampler와 클래스 가중 손실의
    효과를 별도 실험으로 비교
6.  **실용적 학습 파이프라인:** DataLoader 기반 미니배치 학습, 데이터
    증강 및 더 큰 실제 이미지 데이터셋으로 확장
