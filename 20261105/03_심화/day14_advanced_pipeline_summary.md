# 이미지 분류 심화 파이프라인 요약

## 작업 요약

- **학습 및 재개:** 사전학습 CNN의 일부 계층을 미세 조정하고, 미니배치(16개), 클래스 불균형 가중치, AdamW, 학습률 스케줄러를 사용해 최대 4 Epoch 학습한다. 체크포인트에 모델·옵티마이저·스케줄러·난수 상태 등을 저장해 중단 후 재개를 지원한다.
- **데이터 점검:** 매니페스트 기반 중복 이미지 및 그룹 간 데이터 누수 가능성을 검사한다(`audit`).
- **해석 및 신뢰성 진단:** 얕은 층·깊은 층의 Grad-CAM, 상위 활성 영역 가림과 무작위 가림 비교, Occlusion Map을 생성한다(`cam`). 그룹 단위 부트스트랩과 밝기 구간별 성능도 확인한다(`bootstrap`).
- **단계별 미세 조정:** Head 학습 후 새 계층을 옵티마이저에 추가하면서 기존 Head의 옵티마이저 상태가 유지되는지 확인한다(`stages`). CUDA 환경에서는 선택적으로 AMP를 사용할 수 있다.

| 실행 모드 | 핵심 기능 |
|---|---|
| `full` / `part` / `resume` | 4 Epoch 전체 학습 / 2 Epoch까지 학습 / 저장된 상태에서 재개 |
| `audit` | 중복·유사 이미지 및 그룹 누수 점검 |
| `cam` / `bootstrap` | 모델 설명 시각화 / 그룹 기반 불확실성·밝기별 성능 분석 |
| `stages` | 학습 대상 계층 확장 시 옵티마이저 상태 보존 확인 |

## 결론

- 단순 분류 학습을 넘어 **재현 가능한 학습 재개, 데이터 품질 감사, 모델 해석, 그룹 단위 성능 진단**을 통합한 실험용 파이프라인이다.
- 다만 `cam`과 `bootstrap`은 **1 Epoch 초기 후보**로 수행하므로, 그 결과를 최종 모델의 성능이나 신뢰성으로 해석해서는 안 된다. 실제 성능 개선 여부는 실행 결과를 확인해야 판단할 수 있다.

## 한계점

- **독립 Test 평가 부재:** Test를 읽지 않으므로 최종 일반화 성능을 확인할 수 없다. 검증 데이터도 학습 중 모니터링에 사용된다.
- **제한된 실험 범위:** 합성 데이터 기반 사전학습, 작은 CNN, 4 Epoch 및 단일 시드만으로 실환경 성능이나 결과의 안정성을 일반화하기 어렵다.
- **해석의 불확실성:** Grad-CAM과 가림 실험은 모델 반응을 보여줄 뿐 인과적 근거를 입증하지 않는다. 가려진 이미지는 원래 데이터 분포에서 벗어날 수 있다.
- **부트스트랩의 조건부 해석:** 그룹 부트스트랩과 밝기별 분석은 그룹 정의, 표본 수, 1 Epoch 초기 모델의 품질에 민감하다.
- **외부 구현 의존:** `engine`, `models`, `contracts`의 실제 구현이 제시되지 않아 데이터 누수 방지, 체크포인트의 완전한 재현성, AMP 처리의 정확성은 이 코드만으로 검증할 수 없다.
